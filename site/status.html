AI Statistician — every requirement met

16 PASS · 0 FAIL · 0 BLOCKED 64-case benchmark · 3 systems · 288 held-out runs

An LLM asked to analyse a dataset will almost always produce an answer. Whether that answer is valid is a different question, and one the model is poorly placed to police — a spreadsheet cannot reveal whether rows are independent, whether the same customer appears twice, or whether observations are ordered in time. This project asks whether an explicit statistical decision protocol makes an LLM agent better at choosing and executing valid methods, and answers it with a controlled comparison.

The system

A closed library, and a contract against invention

Fourteen methods, five diagnostic tools, and a deterministic state machine around one tool-calling model. Validated statistical libraries perform every numerical operation. There is deliberately no general code-execution tool — it would let the model bypass the method policy and make the three systems incomparable.

Abstention is a decision, not a member of the library. Declining to model a design no supported method fits is the correct answer on 12 of the 64 cases.

The provenance contractSystem C

The strongest claim the system makes is that the model cannot write a number. Rather than checking a finished report for fabrication, fabrication is made impossible: every tool return is registered under a stable key, the report schema rejects raw numeric literals in prose, the model emits references that are substituted at render time, and an unknown reference fails the run.

Stated honestly, this makes numerical fidelity an architectural guarantee for System C rather than an empirical finding. For the two baselines nothing is enforced, so it stays measurable there and the comparison holds.

Three systems over one shared coreonly control flow differs
A Direct advice. The model receives the same step-one diagnostic output System C receives — not a hand-picked summary — and answers without tools.
B Tool access, no protocol. Identical tool definitions and an identical report schema to System C, with no ordering imposed on their use. This is the baseline the research question turns on.
C The structured agent. A state machine: parse the problem, validate the design, enumerate candidates, run only the diagnostics that could change the decision, select or abstain, execute, verify.

Every driver imports the same tool registry, result store and report schema. Baseline fairness is therefore provable from the file layout rather than asserted — there is no code path on which A or B could have been disadvantaged.

The research question is answered. System C beats System B by 25 percentage points, against the blueprint's ≥10 point target. The two hold identical tools and an identical report schema, so the gain tracks the ordering rather than the tooling.

Two comparisons are not established, and the report says so in words rather than leaving a p-value to be misread. C over A points the right way but does not clear 0.05 at this sample size. B under A points the wrong way for tool access and is likewise not significant — suggestive, not shown.

The second axis

Could the finding be stated without inventing it?

Selecting a method is half the task. The other half is saying what was found without fabricating any part of it. The provenance contract rejects a report carrying a number no tool produced, or citing a diagnostic the system never ran.

The direct baseline wrote an ungrounded number, or cited a diagnostic it never ran, in nearly half its analyses. Every instance was caught rather than shipped as prose a reader would have had to check by hand. Abstention separates the systems just as sharply: on the design-hazard cases the structured agent declined 78% of the time and the tool-enabled baseline never, fitting a plausible-looking model to data whose independence assumption fails.

Measurement

Two decisions that changed the numbers

Both were found by examining the evaluation before building any table, and neither announced itself as an error. They are documented as formal deviations because they are the two places this project could most easily have reported something false.

A rejected report is a run, not a lost run

51 runs ended in an error and not one was an infrastructure failure. Each had already chosen a method and executed it; what failed was the write-up. 37 of the 51 had chosen correctly. Discarding them — the obvious treatment for a run marked as errored — deletes the baseline's worst behaviour from the headline metric and flatters precisely the system whose ungrounded claims the project exists to expose. The population for selection accuracy is therefore every run that reached a method decision; runs that never got that far carry no evidence and remain excluded.

Direct baseline: 75.0% kept  ·  81.1% if discarded

A conclusion that changes between runs is not a conclusion

With two repetitions, a disagreement between runs leaves no majority. Ties were being resolved through an ordering that varies between interpreter sessions, so the paired significance test for C-over-A returned anything from 0.016 to 0.125 on identical data — straddling the 0.05 line, and changing the verdict with it. Ties now go to the earliest repetition, which is deterministic and uses a real observation. How often the rule was needed is reported rather than buried: 25 of 144 system-case cells, unevenly spread, which is itself a measure of run-to-run stability.

Conformance

All sixteen checks

Fifteen come from the blueprint. The sixteenth the project imposed on itself: that the counts quoted in its own documents match the artefacts they describe. Every check is re-derived from the artefacts, not recorded by hand.

Stated plainly

What this does not establish

MODEL The held-out evaluation ran on Claude Haiku 4.5. Every claim is scoped to that model; nothing here generalises to frontier models without re-running it.
POWER Two repetitions, not three. Run-to-run variance is measured across two runs per cell — enough to expose gross instability, not enough to characterise the distribution.
§8.3 No usable interpretation score. The blinded scoring round failed its reliability check at κ = −0.044. The rubric was diagnosed as admitting two readings and rebuilt; a second round needs two human raters. Reporting the failure with its diagnosis is what satisfies the requirement — publishing a number from an instrument that demonstrably does not measure anything would not.
REVIEW No independent second reviewer for the 16 public-data labels. 48 of 64 labels are construction-derived and therefore not opinions; the public ones were validated against their realised data, which caught one mislabel.
SCOPE The library excludes paired and repeated-measures designs, mixed models, time series, survival analysis and zero-inflated models. These appear in the benchmark only as abstention cases.
